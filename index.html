My Projects

These are some of the hands-on cybersecurity and networking projects I have completed throughout my computer technology coursework. These projects gave me experience working with network attacks, firewalls, packet analysis, Linux, and network security tools.

Mitnick Attack Lab

In the Mitnick Attack Lab, I created a controlled network environment using Docker containers to understand how a TCP session hijacking attack works. I used Scapy for packet sniffing and spoofing and worked with TCP connections to examine how an attacker could take advantage of trusted-host authentication.

During the lab, I worked with the rsh protocol and manipulated network communication to execute a remote command on the target system. I was also able to create a .rhosts backdoor and verify that the attack was successful. I used Wireshark to examine the network traffic and better understand what was happening during each stage of the attack.

Skills & Technologies: Docker, Scapy, Wireshark, TCP/IP, Packet Sniffing, Packet Spoofing, TCP Session Hijacking, Linux, rsh

Firewall Exploration Lab

In the Firewall Exploration Lab, I created a network environment using Linux and Docker containers to learn how firewalls inspect and control network traffic. I worked with Linux kernel modules and Netfilter to intercept packets and examine TCP, UDP, ICMP, and DNS traffic.

I also created and tested firewall rules using iptables. I worked with INPUT, OUTPUT, and FORWARD rules and tested how different rules affected DNS requests, ping traffic, and TCP connections. I also explored stateless and stateful packet filtering, used conntrack to examine connections, and worked with rate limiting to control network traffic.

Skills & Technologies: Linux, Docker, Netfilter, iptables, Kernel Modules, TCP, UDP, ICMP, DNS Filtering, Stateful Filtering, Stateless Filtering, Conntrack, Rate Limiting

Wireshark Packet Analysis Lab

In the Wireshark Packet Analysis Lab, I analyzed captured network traffic to investigate suspicious activity. I used Wireshark to examine packets and identify information such as source and destination IP addresses, MAC addresses, protocols, and other details contained within network communications.

I also analyzed HTTP traffic and inspected HTTP POST data to better understand the activity taking place on the network. By following the packets and comparing information from different parts of the capture, I was able to reconstruct a timeline of activity and identify where suspicious web traffic originated. This project helped strengthen my packet analysis, troubleshooting, and network investigation skills.

Skills & Technologies: Wireshark, Packet Analysis, HTTP, TCP/IP, IP Addresses, MAC Addresses, HTTP POST Analysis, Network Forensics, Traffic Analysis
