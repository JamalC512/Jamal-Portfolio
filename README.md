## Projects

### Mitnick Attack Lab
Created a controlled Docker environment to study TCP session hijacking. Worked with Scapy, packet sniffing, packet spoofing, TCP sequence numbers, trusted rsh relationships, and Wireshark traffic analysis.

### Firewall Exploration Lab
Worked with Linux, Docker, Netfilter, and iptables to examine firewall behavior and network traffic. Tested TCP, UDP, ICMP, DNS filtering, stateful and stateless packet filtering, connection tracking, and rate limiting.

### Wireshark Packet Analysis Lab
Analyzed captured network traffic using Wireshark to investigate suspicious HTTP activity. Examined IP addresses, MAC addresses, protocols, HTTP POST data, and network traffic to reconstruct a timeline of activity.
